# Code of Conduct

## Our standard

Be direct, technical and respectful. Disagreement about code and design is welcome; personal attacks,
harassment, discrimination and publishing another person's private data are not.

Examples of expected behavior:

- Critique the change, not the person.
- Give reproducible examples and assume good faith.
- Respect privacy: redact device data, paths, package names and credentials.
- Accept that 1.0 software has documented limits and known limitations, and report them honestly.

## Scope

This applies to issues, pull requests, discussions, reviews and other project spaces.

## Enforcement

Maintainers may edit or remove content, close threads, or block accounts that violate this policy.
Report conduct problems privately to the maintainer through the GitHub profile linked on the
repository. Security vulnerabilities follow [SECURITY.md](SECURITY.md), not this process.

## Attribution

This is a short project-specific policy, not a legal document. It is informed by common open-source
codes of conduct, including the Contributor Covenant.
