# Scoop manifest

This manifest targets the portable v0.11.0 release asset and pins its published SHA-256. Validate the
downloaded GitHub release asset locally before publishing the manifest. It is **not** submitted to or
accepted by the official Scoop bucket. Do not describe it as available from Scoop until a bucket
maintainer publishes it.

Winget manifests were not published; the portable ZIP and Inno Setup installer are the supported
distribution formats for v0.11.0.
