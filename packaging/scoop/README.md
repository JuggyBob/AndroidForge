# Scoop manifest

This manifest targets the portable v0.7.1 release asset and pins its published SHA-256. It has been
validated against the downloaded GitHub release asset locally, but it is **not** submitted to or accepted
by the official Scoop bucket. Do not describe it as available from Scoop until a bucket maintainer
publishes it.

Winget manifests were not published; the portable ZIP and Inno Setup installer are the supported
distribution formats for v0.7.1.
