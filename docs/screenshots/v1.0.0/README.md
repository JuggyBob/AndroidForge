# AndroidForge v1.0.0 screenshots

Five real captures of the compiled v1.0.0 native desktop cockpit. They were taken on Windows with the
IronPulse project selected and an isolated AndroidForge home. No mockups or browser-rendered UI are
included.

Two captures show the environment-validation state visible at capture time (no AVDs/SDK state): Setup
and Overview. That is the condition of this capture session, not a product failure. The other three
images are the polished showcase and are the ones featured in the main README.

| File | Page |
| --- | --- |
| `01-setup.png` | Setup wizard; shows the environment-validation warning (no AVDs/SDK state), so it is not a lead image |
| `02-tool-database.png` | Tool database with 191 commands and safety labels — showcase |
| `03-overview.png` | Overview dashboard; shows the same environment-validation warning, so it is not a lead image |
| `04-ownership.png` | Ownership: sessions, leases and safe alternatives — showcase |
| `05-triage.png` | Failure triage and deterministic explanation — showcase |

## Notes

- All captures are from Windows at a high-DPI scale. Screenshots may contain local project paths and
  emulator labels; review or redact them before reusing in a different environment.
- The binaries are intentionally unsigned, so Windows SmartScreen may warn on first launch.
- The five captures are published as `androidforge-screenshots-v1.0.0.zip` when the screenshot ZIP is
  produced. See the [v1.0.0 release notes](../../release-notes/v1.0.0.md) for release assets.
