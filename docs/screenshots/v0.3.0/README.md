# AndroidForge v0.3.0 screenshots

These are real screenshots of the compiled native application running against an Android 16 emulator
and the CalcSuite project. They are not mockups.

The `overview-*.png` files are client-area captures at the requested logical sizes:

- `overview-1280x720.png` — 1280×720 logical (captured at 125% Windows scaling).
- `overview-1366x768.png` — 1366×768 logical.
- `overview-1920x1080.png` — 1920×1080 logical.

The remaining files are validation captures for the main workflows at 1280×720 logical unless noted.
They were taken from the same build and show real backend data:

- `setup-onboarding-1280x720.png` — first-launch setup wizard.
- `triage-1280x720.png` — failure triage and flaky analysis.
- `compare-1280x720.png` — compatible run comparison.
- `logcat-live-1280x720.png` — live logcat with streaming status.
- `inspector-1280x720.png` — preview, semantic hierarchy and node details.
- `maintenance-cleanup-1280x720.png` — cleanup preview before confirmation.
- `settings-1280x720.png` — connection, workspace, theme and update settings.

All captures are client-area screenshots of the application window; no third-party desktop content is
included. Binaries and assets are unsigned.
