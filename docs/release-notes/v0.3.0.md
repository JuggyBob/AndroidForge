# AndroidForge v0.3.0 (Alpha)

AndroidForge v0.3.0 is the first release where the native desktop cockpit feels like a complete
developer tool rather than a prototype around the CLI. The CLI remains authoritative: every desktop
feature drives the same commands and JSON contracts documented in the repository.

## Highlights

### Onboarding and diagnostics
- First-run setup wizard for CLI discovery/compatibility, Android SDK, ADB, emulator, Java and AVDs.
- Actionable doctor output with required/optional status, blocking impact and suggested fixes.
- Workspace and project adapter selection, plus a safe device verification step that never installs an
  APK or resets user data.

### Analysis and debugging
- Failure triage with build identity, failure metadata, artifacts and links to live views.
- Compatible run comparison with build/environment warnings, regressions and duration deltas.
- Flaky-step analysis with a transparent minimum-run heuristic and observation history.
- Copyable Markdown/JSON summaries and artifact-folder access.
- Startup reconciliation for interrupted runs, with `cancelled`, `interrupted`, `timed_out` and
  `abandoned` lifecycle outcomes.

### Live device tools
- Bounded live logcat with package/level/search filters, pause/resume, follow-latest, crash/ANR
  highlighting, disconnect state and export.
- Periodic device preview with a parsed UIAutomator hierarchy, tree expansion/search/raw XML, bounds
  highlighting, selector copying and semantic tap/long-press/type/scroll/back/home actions. This is
  periodic screenshot capture, not a video-streaming replacement.

### Safe maintenance and updates
- Maintenance center with storage accounting and dry-run previews before deletion.
- Active sessions and running runs are never removed. Only terminal tombstones and historical runs
  inside AndroidForge-managed storage are eligible.
- Update checks use the official GitHub release; CLI repair downloads are verified against the
  published SHA-256 before staging and are rolled back if validation fails.

### Packaging
- Portable Windows x86_64 ZIP containing both executables, docs and license.
- Per-user Windows installer with Start Menu shortcut, optional desktop shortcut and uninstaller.
- SHA-256 checksums for every asset.

## Download assets

| Asset | Purpose |
| --- | --- |
| `androidforge-desktop-windows-x86_64.zip` | Portable desktop + CLI; keep both executables together. |
| `androidforge-windows-x86_64-setup.exe` | Per-user installer; no administrator rights required. |
| `androidforge-cli-windows-x86_64.zip` | Standalone CLI for `PATH`/automation and the desktop repair path. |
| `SHA256SUMS.txt` | Verify every downloaded asset before running it. |

## Important notes

- **Unsigned binaries.** These assets are intentionally unsigned. Windows SmartScreen may warn on first
  launch. No publisher identity or code-signing certificate is claimed.
- The desktop requires the adjacent `androidforge.exe` (or a configured compatible path) and refuses a
  CLI whose version or JSON schema does not match.
- Physical-device, Maestro, instrumentation-package, snapshot-restore and root-only paths remain
  unvalidated in this release.
- AndroidForge does not silently download or execute installers, does not collect telemetry and does
  not clear the device's global log buffers to start the live view.
