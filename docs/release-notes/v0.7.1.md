# AndroidForge v0.7.1 (Alpha) - Desktop Retry Presentation

This is a patch to the v0.7.0 Matrix & Device Control line. It does not change the v0.7.0 release or its
tag/assets.

## Change

The desktop Logcat panel now calls the CLI logcat peek with bounded read-only retries (`--retries 2`) and
surfaces the returned retry report in its status notes. Operators can see when a transient device or
UIAutomator read failure required a retry instead of the desktop silently presenting only the final
lines.

This completes the v0.7.0 desktop presentation requirement for retry attempts and transient failures.
The retry engine remains CLI-authoritative; the desktop does not implement its own retry logic.

## Compatibility

- CLI, desktop, installer and portable package are `0.7.1`.
- All v0.7.0 matrix, element-reference, wireless/health, receipt, recurrence, APK and bundle behavior is
  unchanged.
- The v0.7.0 GitHub release remains intact.
